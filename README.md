# editor-assets
Creatorlink editor static assets

## 견본 사진 · 영상 주소 규칙 (261119)
- slide · board · text · gallery(product_peace · product_still 제외) 견본은 이 저장소가 아니라 editor.html 의 `CL_ASSET`(사이트 저장소 https://storage.googleapis.com/i.addblock.net/)을 쓴다.
- content-sample 은 editor.html 의 `CN_CL` 목록에 있는 파일만 `CL_ASSET`, 나머지는 이 저장소.
- 이 저장소의 해당 사본은 옛 편집기 파일용으로 잠시 남겨 둔 것 — 새 블록에서 이 주소를 쓰지 않는다.
- 이 저장소에 두는 것: 편집기에서 만든 자산(ba/ · help/ · 폰트)과 사이트에 없는 견본(content-sample 대부분 · image-sample · etc-sample · gallery-sample/sample/product_*).
